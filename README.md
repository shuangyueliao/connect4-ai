# Connect Four · 4 in a Row vs AI

Free single-file HTML5 strategy game. Classic Connect Four against a
minimax AI with alpha-beta pruning — three difficulty levels (Easy,
Normal, Hard), first-move choice (You / AI / Random), per-difficulty
win/loss/draw records. One HTML file, zero assets.

**Play:** https://shuangyueliao.github.io/connect4-ai/

- Mouse / touch / arrow keys, procedural WebAudio sounds
- Procedural canvas visuals, no dependencies
